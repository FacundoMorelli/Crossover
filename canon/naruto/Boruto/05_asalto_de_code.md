# Asalto de Code
PARTE: NNG
CAPÍTULOS DEL MANGA: 56–67 (vol. 15–17)
LUGARES: Konohagakure; complejo de culto de Boro (donde Code recluta a Eida y Daemon); campo de batalla fuera de la aldea (Code vs Boruto y Kawaki); dimensión de Kara.
DURACIÓN EN LA HISTORIA: semanas.
ESTACIÓN / MOMENTO DEL AÑO: no indicada.

PERSONAJES PRESENTES:
- Boruto Uzumaki (genin; Karma), Kawaki (Karma nuevo), Sarada, Mitsuki, Sumire Kakei (ninja de Konoha; diseñadora de Nue/tecnología), Konohamaru.
- Naruto (Séptimo Hokage, sin Kurama), Hinata, Himawari, Shikamaru, Sasuke (sin Rinnegan).
- Amado (científico, ahora en Konoha), Delta.
- Code (Karma Blanco; limitadores).
- Eida (Externa; Senrigan; encanto) y Daemon (Externo; reflejo).
- Momoshiki (en Boruto).

QUÉ PASA:
1. Konoha investiga los restos de Kara y oculta el incidente del Karma. El Equipo 7 queda en pausa.
2. Amado reconstruye el brazo de Kawaki y da a Boruto medicina para frenar el Karma. Kawaki propone implantar a Code el Karma de Boruto como plan de contingencia.
3. Amado ofrece a Kawaki un nuevo Karma; él lo rechaza. Sumire sospecha de Amado.
4. Code recluta a Eida y Daemon en el complejo de Boro. Eida tiene el Senrigan y encanta a todos salvo a Ōtsutsuki y parientes de sangre. Code acepta el plan de Eida para obligar a Amado a quitarle sus limitadores.
5. Aparecen Marcas de Garra (Claw Marks) de Code por la aldea. Code prueba el reflejo de Daemon y se dirige a Konoha.
6. Naruto acepta a Kawaki como hijo. Fiesta de bienvenida; Boruto le regala su vieja bandana.
7. Amado advierte a Shikamaru que el apego de Kawaki a Naruto roza la locura.
8. Kawaki sale en secreto de la aldea con poderes Ōtsutsuki (Karma reinstalado) y se encuentra con Code. Boruto lo rastrea. Pelean juntos contra Code. Boruto despierta en su ojo derecho el ojo de Momoshiki (luego confirmado como Byakugan).
9. Boruto usa la esencia del Karma y combate con Kawaki. Naruto y Shikamaru van al campo.
10. Momoshiki toma el control: domina a Code, intenta llevarse a Kawaki y luego se alía con Code para matar al Hokage.
11. Kawaki pelea con Momoshiki usando las habilidades de Isshiki hasta que Boruto recobra la conciencia y le pide que lo mate. Kawaki lo atraviesa; Code usa a Daemon para reflejar el ataque y deja inconsciente a Kawaki. Code se retira.
12. Boruto se recupera y consuela a Naruto. Flashback: Momoshiki reparó la herida de Boruto con Karma incompleto, sacrificando su capacidad de reencarnar.
13. Code se prepara para infiltrarse en la aldea.

PELEAS DEL ARCO:
1. Boruto y Kawaki vs Code — fuera de Konoha — sin resolución; Momoshiki toma el control.
2. Momoshiki (en Boruto) vs Code — Momoshiki domina.
3. Kawaki vs Momoshiki (en Boruto) — Kawaki hiere de muerte a Boruto; Daemon refleja el daño; Code se retira.

TÉCNICAS MOSTRADAS POR PRIMERA VEZ:
- Code: Marcas de Garra (bandas negras para teletransportarse); Karma Blanco; fuerza física extrema; limitadores impuestos por Amado.
- Eida: Senrigan (ver cualquier lugar y tiempo actual); encanto (Charm) que hace que todos la amen.
- Daemon: Reflejo (devuelve la intención asesina/daño al atacante).
- Boruto: despertar del ojo derecho (de Momoshiki; en TBV se confirma Byakugan); "esencia" del Karma.
- Kawaki: Karma reinstalado con las habilidades de Isshiki (Sukunahikona, Daikokuten).
- Momoshiki (en Boruto): técnicas Ōtsutsuki con el cuerpo de Boruto.

MUERTES:
- Boruto — herido de muerte por Kawaki; REVIVE gracias a Momoshiki (Karma incompleto).

MOMENTOS CLAVE / GIROS:
- Momoshiki puede tomar a Boruto y pierde la opción de reencarnar.
- Kawaki está dispuesto a matar a Boruto para impedir el regreso de Momoshiki.
- Aparecen Eida y Daemon.

EN PARALELO:
- Code prepara su infiltración.

QUÉ CAMBIA DESPUÉS:
- Kawaki con Karma reinstalado.
- Boruto con el ojo derecho despertado.
- Code aliado (por ahora) con Eida y Daemon.

DUDAS O CONTRADICCIONES ENTRE FUENTES:
- Narutopedia no fue accesible; rango 56–67 confirmado con fuente secundaria.
- Secuencia exacta del golpe de Kawaki y la intervención de Daemon: una fuente lo resume como reflejo del ataque y otra describe que Kawaki mató a Boruto y Momoshiki lo salvó. Ambas coinciden en que Boruto sobrevive por Momoshiki.
